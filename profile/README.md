## Meet Copily

**Your clipboard, ready when you need it.**

A native macOS clipboard manager with searchable history, permanent collections,
code previews, and color swatches. Keep useful text, links, images, and files close at hand.

[**Download for Mac (.dmg)**](https://github.com/Free-Apps-4-You/copily/releases/download/v0.1.0/Copily-0.1.0-arm64.dmg) · [Application ZIP](https://github.com/Free-Apps-4-You/copily/releases/download/v0.1.0/Copily-0.1.0-arm64.zip) · [Explore Copily](https://github.com/Free-Apps-4-You/copily)

Apple Silicon · macOS 14+ · MIT licensed
